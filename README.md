## 🇧🇷 Português

### Portal do Cliente — área logada de frota

**Role / Papel / Rol:** Frontend SPA completo  
**Stack:** `React 19, TypeScript, Vite, React Router, Recharts, CSS Modules`

#### Problem / Problema
Clientes precisavam de uma área web moderna para acompanhar frota e consumo, alinhada visualmente ao restante do produto (DASH_BI).

#### Solution / Solução / Solución
Criei SPA em React/TS com design tokens compartilhados, gráficos e roteamento — rodando em porta dedicada ao lado do dashboard principal.

#### Highlights
- React 19 + Vite + TypeScript
- Gráficos (Recharts)
- Design system alinhado ao BI
